# Road-Accident-Analysis-Project
An end-to-end data analytics project that demonstrates data cleaning, modelling, visualization, and dashboard creation using SQL, Excel, Tableau, and Power BI.This repository contains a full data analytics project, showcasing the complete lifecycle: data extraction, cleaning, transformation, analysis, and visualization. Tools used include SQL, Excel, Tableau and Power BI. The project presents dashboards and insights, and serves as a portfolio piece to demonstrate capabilities in data analytics
